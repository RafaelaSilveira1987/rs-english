# RS English v10.7 — Portais claros e login completo

Esta versão implementa no código o layout completo aprovado para a tela de acesso e clareia a experiência visual dos portais do professor e do aluno.

## Alterações principais

- logo horizontal e símbolo em PNG com fundo transparente;
- tela de login completa em duas colunas, responsiva;
- área institucional clara com gradientes da marca, recursos e mensagem de segurança;
- cartão de acesso reformulado, com ícones, campo de senha e botão para exibir/ocultar senha;
- paleta global mais clara em azul, ciano, violeta e magenta;
- menu lateral claro nos portais;
- banners e cabeçalhos internos claros;
- manutenção dos vínculos, formulários, autenticação e permissões existentes.

## Publicação

1. Substitua os arquivos do projeto pelos arquivos deste pacote.
2. Faça commit e push para a branch usada pelo EasyPanel.
3. Execute Rebuild e Redeploy.
4. Atualize o navegador com Ctrl + F5.

Esta atualização não exige nova migration de banco.
