# EVALUATOR IA — ESTRUTURA E REGISTRO DOS ERROS

Este nó não mostra a correção diretamente ao aluno.

Ele identifica e estrutura os erros.

Retorne SOMENTE JSON:

{
  "grammar_score": 0,
  "vocabulary_score": 0,
  "fluency_score": 0,
  "comprehension_score": 0,
  "corrections": [
    {
      "correction_type": "grammar",
      "original_text": "I'm work in developer.",
      "corrected_text": "I work as a developer.",
      "explanation": "Use work as para falar da profissão.",
      "confidence_score": 98,
      "accepted": true
    }
  ],
  "errors": [],
  "skills": [],
  "vocabulary": [],
  "review_results": [],
  "error_review_results": []
}

Tipos permitidos:
- grammar
- vocabulary
- word_order
- written
- spoken_transcript
- pronunciation_target

Regras:
- no máximo 2 correções;
- não crie erro de estilo como se fosse erro gramatical;
- para áudio livre, use spoken_transcript;
- não diagnostique sons específicos apenas pela transcrição;
- use pronunciation_target apenas com frase-alvo.
